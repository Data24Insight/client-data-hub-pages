Google API 접근 범위 안내

고객 Data Hub 개인정보처리방침

이 문서는 "고객 Data Hub"가 Google 계정에 요청하는 단 하나의 권한 — Gmail 발송 전용(gmail.send) — 을 어떤 목적으로, 어떻게 사용하는지 설명합니다.

  • 권한 범위발송 전용
  • 받은편지함 접근없음
  • 제3자 데이터 공유없음
  • 이메일 내용 저장없음

이 앱은 무엇인가요

"고객 Data Hub"는 이노뎁(Innodep) 사내에서 지방자치단체 고객사의 운영 데이터를 담당자가 조회할 수 있게 모아두는 내부 업무 도구입니다. 일반에 공개된 서비스가 아니며, 소속 직원만 로그인해 사용합니다.

Gmail 권한을 요청하는 이유

이 시스템은 새벽 시간대를 포함해 하루 여러 차례 외부 시스템(Salesforce, Jira)과 데이터를 자동으로 동기화합니다. 이 동기화가 실패하면 담당자가 즉시 알 수 있도록, 지정된 관리자 이메일 한 곳으로 실패 알림 메일을 자동 발송합니다. gmail.send 권한은 오직 이 알림 메일을 보내는 데에만 쓰입니다.

이 권한으로 하지 않는 것

  • 받은편지함의 메일을 읽거나 검색하지 않습니다
  • 메일을 삭제하거나 수정하지 않습니다
  • 연락처, 라벨 등 다른 Google 계정 데이터에 접근하지 않습니다
  • 발송한 메일의 내용을 별도로 수집·저장·분석하지 않습니다
  • 이 권한으로 얻은 어떤 정보도 제3자와 공유하지 않습니다

데이터 보관

알림 메일은 발송과 동시에 처리가 끝나며, 이 권한과 관련해 별도로 보관하는 데이터는 없습니다. 시스템 자체 운영 로그에는 "발송 성공/실패" 여부와 시각만 텍스트로 짧게 남으며, 이는 시스템 안정성 점검 목적의 사내 로그일 뿐 Gmail 데이터가 아닙니다.

적용 범위

이 방침은 위에서 설명한 Gmail 발송 기능 하나에 한정됩니다. "고객 Data Hub"가 다루는 지자체 고객사 데이터 전반의 취급 방식은 이노뎁의 별도 사내 정책을 따르며, 이 페이지의 대상이 아닙니다.
