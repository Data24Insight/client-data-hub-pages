고객 Data Hub

지방자치단체 고객사에 관한 정보가 Salesforce와 Jira에 흩어져 있는 문제를 해결하기 위해, 이노뎁(Innodep) 담당자가 사이트 단위로 한눈에 조회할 수 있도록 모아 보여주는 내부 업무 도구입니다.

  • 사용 대상이노뎁 소속 직원
  • 공개 여부로그인 필요, 비공개
  • 데이터 원천Salesforce · Jira
  • 외부 API 사용Gmail 발송 전용

무엇을 하나요

민원·계약·유지보수·개발 이슈처럼 시스템마다 나뉘어 있던 고객사 데이터를 15분~30분 주기로 자동 동기화해 하나의 화면에서 사이트별로 볼 수 있게 합니다. 담당자가 여러 시스템을 오가지 않고도 한 고객사의 전체 이력을 파악할 수 있도록 돕는 것이 이 도구의 유일한 목적입니다.

왜 Gmail 권한을 요청하나요

자동 동기화가 실패했을 때 관리자에게 즉시 알리기 위해, Gmail API의 발송 전용(gmail.send) 권한만 사용합니다. 받은편지함 접근이나 데이터 수집은 하지 않으며, 자세한 내용은 개인정보처리방침에서 확인하실 수 있습니다.
